================================================================================
                          1️⃣ جداول قاعدة البيانات
================================================================================

جدول: webhooks
-----------------
id                  INT PRIMARY KEY AUTO_INCREMENT
whatsapp_instance_id INT (foreign key -> whats_app_instances.id)
name                VARCHAR(255)
url                 VARCHAR(500)
events              JSON/TEXT (array of strings)
secret              VARCHAR(255) NULLABLE
is_active           BOOLEAN DEFAULT true
total_calls         INT DEFAULT 0
success_rate        DECIMAL(5,2) DEFAULT 100.00
last_triggered      TIMESTAMP NULLABLE
created_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP
updated_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

مثال لـ events JSON:
["message.received", "message.sent", "message.delivered"]


جدول: webhook_events (سجل الأحداث)
-----------------
id                  INT PRIMARY KEY AUTO_INCREMENT
webhook_id          INT (foreign key -> webhooks.id)
event_type          VARCHAR(100)
payload             JSON/TEXT
response_status     INT
response_time       INT (milliseconds)
success             BOOLEAN
created_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP

مثال لـ payload JSON:
{
  "message_id": 123,
  "from": "218xxxxxxxx",
  "text": "مرحبا",
  "timestamp": "2025-12-09T20:30:00"
}


جدول: api_keys
-----------------
id                  INT PRIMARY KEY AUTO_INCREMENT
whatsapp_instance_id INT (foreign key -> whats_app_instances.id)
name                VARCHAR(255)
key                 VARCHAR(255) UNIQUE (مشفر)
permissions         JSON/TEXT (array of strings)
is_active           BOOLEAN DEFAULT true
created_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP
last_used           TIMESTAMP NULLABLE
updated_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

مثال لـ permissions JSON:
["messages.send", "messages.read", "contacts.read"]

ملاحظة: المفتاح key يجب تشفيره (hashing) قبل التخزين


================================================================================
                              2️⃣ API Routes
================================================================================

جميع الـ routes تبدأ بـ: /api/whatsapp/instances/{instance_id}/

------------------------
WEBHOOKS ROUTES:
------------------------

GET     /webhooks
        Response: { data: [Webhook Array], message: "success" }

GET     /webhooks/{webhook_id}
        Response: { data: Webhook Object, message: "success" }

POST    /webhooks
        Body: {
          name: string,
          url: string,
          events: string[],
          is_active: boolean
        }
        Response: { data: Webhook Object, message: "Webhook created successfully" }

PUT     /webhooks/{webhook_id}
        Body: {
          name: string,
          url: string,
          events: string[],
          is_active: boolean
        }
        Response: { data: Webhook Object, message: "Webhook updated successfully" }

DELETE  /webhooks/{webhook_id}
        Response: { message: "Webhook deleted successfully" }

POST    /webhooks/{webhook_id}/toggle
        Response: { data: { is_active: boolean }, message: "Webhook status toggled" }

POST    /webhooks/{webhook_id}/test
        يرسل حدث تجريبي إلى الـ webhook URL
        Response: { message: "Test event sent successfully" }

GET     /webhooks/{webhook_id}/events?limit=50
        Response: { data: [WebhookEvent Array], message: "success" }


------------------------
API KEYS ROUTES:
------------------------

GET     /api-keys
        Response: { data: [ApiKey Array], message: "success" }
        ملاحظة: يجب عدم إرجاع المفتاح الكامل، فقط جزء منه مخفي

GET     /api-keys/{key_id}
        Response: { data: ApiKey Object, message: "success" }

POST    /api-keys
        Body: {
          name: string,
          permissions: string[]
        }
        Response: {
          data: {
            ...ApiKey Object,
            key: "full_api_key_here"  // يظهر مرة واحدة فقط
          },
          message: "API Key created successfully"
        }
        ملاحظة هامة: المفتاح الكامل يجب أن يُرجع فقط عند الإنشاء

PUT     /api-keys/{key_id}
        Body: {
          name: string,
          permissions: string[],
          is_active: boolean
        }
        Response: { data: ApiKey Object, message: "API Key updated successfully" }

DELETE  /api-keys/{key_id}
        Response: { message: "API Key deleted successfully" }

POST    /api-keys/{key_id}/toggle
        Response: { data: { is_active: boolean }, message: "API Key status toggled" }


================================================================================
                      3️⃣ أنواع الأحداث المتاحة (Events)
================================================================================

الأحداث التي يمكن الاشتراك فيها عبر Webhooks:

1. message.received      -> عند استلام رسالة جديدة
2. message.sent          -> عند إرسال رسالة
3. message.delivered     -> عند تسليم الرسالة للمستلم
4. message.read          -> عند قراءة الرسالة من المستلم
5. contact.created       -> عند إضافة جهة اتصال جديدة
6. group.created         -> عند إنشاء مجموعة جديدة
7. status.changed        -> عند تغيير حالة الاتصال (متصل/غير متصل)
8. qr.updated            -> عند تحديث QR code

مثال Payload للـ Webhook:
{
  "event": "message.received",
  "instance_id": "123",
  "timestamp": "2025-12-09T20:30:00Z",
  "data": {
    "message_id": "ABC123",
    "from": "218xxxxxxxx",
    "text": "مرحبا",
    "type": "text"
  }
}


================================================================================
                    4️⃣ الصلاحيات المتاحة (Permissions)
================================================================================

الصلاحيات التي يمكن منحها لمفاتيح API:

1. messages.send         -> إرسال رسائل
2. messages.read         -> قراءة الرسائل
3. contacts.read         -> قراءة جهات الاتصال
4. contacts.manage       -> إدارة جهات الاتصال (إضافة/تعديل/حذف)
5. groups.read           -> قراءة المجموعات
6. groups.manage         -> إدارة المجموعات (إنشاء/تعديل/حذف)
7. instance.read         -> قراءة بيانات الجلسة
8. instance.manage       -> إدارة الجلسة (تعديل الإعدادات)


================================================================================
                          5️⃣ تفاصيل إضافية مهمة
================================================================================

🔐 الأمان (Security):
---------------------
- يجب تشفير API Keys باستخدام bcrypt أو hash مشابه
- يجب التحقق من صلاحيات API Key قبل السماح بأي عملية
- يجب إضافة rate limiting على الـ endpoints
- يُفضل إضافة webhook signature للتحقق من صحة الطلبات

📊 الإحصائيات:
---------------------
- تحديث total_calls عند كل استدعاء للـ webhook
- تحديث success_rate بناءً على response_status
- تحديث last_triggered عند كل استدعاء ناجح
- تحديث last_used في api_keys عند استخدام المفتاح

🔄 Webhook Execution:
---------------------
- عند حدوث event، إرسال POST request إلى webhook URL
- تسجيل النتيجة في webhook_events
- إعادة المحاولة 3 مرات في حالة الفشل
- Timeout: 30 ثانية للـ webhook response

📝 Validation Rules:
---------------------
Webhooks:
  - name: required, max 255 characters
  - url: required, valid URL format
  - events: required, array, at least 1 event

API Keys:
  - name: required, max 255 characters
  - permissions: required, array, at least 1 permission
  - key: auto-generated, format: "sk_live_" + 32 random characters
